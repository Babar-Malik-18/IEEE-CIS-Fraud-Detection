Research Paper Reference & Context

"Intelligent approach to detecting online fraudulent trading with solution for imbalanced data in fintech forensics"

Published in Scientific Reports (Nature Portfolio), 2025, 15:17983. DOI: 10.1038/s41598-025-01223-8

Key Research Problems Addressed:

  • Severe Class Imbalance: In real fintech transactions, fraudulent instances constitute less than 3.5% of total volume, causing standard learners to bias toward the majority class.
  • Dynamic Fraud Strategies: Attackers continuously alter IP origins, card ranges, and transaction times to bypass rigid rules.
  • Computational Efficiency in Production: Fraud detection systems in high-frequency trading must reach decisions within milliseconds.

System Architecture Implemented:

This full-stack implementation packages the fitted high-performing Random Forest model into a standardized pipeline with verified 68-feature input schemas, local Flask REST API inference, and an Angular 22 dashboard with automated GitHub Actions CI/CD.
